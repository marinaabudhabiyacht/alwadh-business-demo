# ALWADH BUSINESS — Demo

Standalone static interactive sales demonstration using **fictional data only**. It does not connect to Supabase, the production API, or any real customer records. Changes are temporary and reset on refresh. This is a limited simulator, not the full business app.

## Publish

In GitHub repository **Settings → Pages → Build and deployment**, select **Deploy from a branch**, branch **main**, folder **/(root)**, then click **Save**.

Once GitHub Pages reports successful deployment, the demo URL should be:

https://marinaabudhabiyacht.github.io/alwadh-business-demo/
